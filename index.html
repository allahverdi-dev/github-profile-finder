          About

          GitHub Profile Finder is a front-end portfolio project. It looks up public GitHub profiles and repositories through the public GitHub REST API, directly from your browser.

          There is no backend, no account and no data storage — only your theme preference is kept locally. Unauthenticated API requests are rate limited by GitHub to 60 per hour per IP address.
